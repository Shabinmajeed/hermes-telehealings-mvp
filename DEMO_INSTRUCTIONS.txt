🚀 TO RUN THE ACTUAL REACT NATIVE APP:

From packages/mobile/:

For Expo Web (Browser):
  npm install --legacy-peer-deps
  npm start -- --web

For iOS Simulator (Mac only):
  npm install --legacy-peer-deps
  npm start
  Press 'i'

For Android Emulator:
  npm install --legacy-peer-deps
  npm start
  Press 'a'
