Body text uses 15px with 1.5 line height for readable copy. The muted text style is ideal for supportive labels and captions.

Small text uses 13px for meta labels, helper text, and less important details.

Core components

Reusable UI pieces from the current pages. These are the building blocks for onboarding, booking, and profile screens.

Buttons

Primary buttons are the strongest CTA. Outline buttons are ideal for secondary actions. The circular style is useful for compact icon-based actions.

Forms

Inputs should be tall, well-spaced, and easy to tap. Use clear labels and strong focus outlines for accessibility.

Accessibility

Modern interface design should also be inclusive. These rules help ensure the experience works for everyone.

  • Keep text contrast high enough for readability.
  • Use focus-visible outlines for keyboard users.
  • Keep interactive targets at least 44px tall.
  • Use semantic HTML and clear labels for form controls.
