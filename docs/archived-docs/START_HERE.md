## 🚀 QUICK START

### 1. Configure Database (5 min)
```bash
# Set DATABASE_URL in .env.local
echo 'DATABASE_URL="postgresql://..."' >> \
  packages/backend/.env.local
```

### 2. Run Migrations (2 min)
```bash
cd packages/backend
npx prisma migrate dev --name init
```

### 3. Fix CORS (2 min)
```typescript
// Add to main.ts
app.enableCors({
  origin: ['http://localhost:5173'],
  credentials: true,
});
```

### 4. Start Services
```bash
# Terminal 1
npm run start:backend

# Terminal 2
npm run start:mobile

# Terminal 3
npm run start:therapist

# Terminal 4
npm run start:admin
```
