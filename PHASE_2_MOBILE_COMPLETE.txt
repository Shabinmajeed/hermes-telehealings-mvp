📱 PHONE AUTH SCREEN
━━━━━━━━━━━━━━━━━━━
Features:
  • 2-step flow: Send OTP → Verify OTP
  • Phone number formatting
  • 6-digit OTP input with visual indicators
  • Resend OTP with countdown timer
  • Error handling & validation
  • Loading states
  • Animations (fade, slide, shake)
  • JWT token auto-storage

API Endpoints:
  POST /auth/send-otp          → Send OTP
  POST /auth/verify-otp        → Verify & authenticate
